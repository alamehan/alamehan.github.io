### The system
Developed **The New E-Systems** — a standardized, international design system for consistency, scalability, and usability — then refined it into **Design System V2** with updated guidelines, enhanced components, and improved visuals. At maturity: foundations (colors, styles, effects, animated GIF illustrations) and **over 70 hand-crafted components**, fully synced, documented in tiers — Atomic, Basic, Advanced, and Panel Content — plus prototype-purpose components and master data.

### Component-architecture practice
Avoid overly complex hierarchies · edit instances first, then *Push to Master* to prevent crash-inducing mass updates · keep the system in its own library file loaded into per-feature files · use Figma **Slots** for variants without break/detach — a 100% synced design system.

### The AI leap
Converted the design system into **JSON** — machine-readable and AI-ready (built with Figma Agents and Claude); began implementing it across the development team so built products stay perfectly consistent with design; and started a **Figma plugin** that auto-generates designs synced to the system from JSON input. One JSON, two outputs: Figma designs and frontend code.

### Redesign scope
Design System · Candidates · Resume Builder · Consent Management · Maintenance Mode · Data Import & Related · File Management · Asset Management · Report Module · Notification Center · Comment Feature · AI-Related Features · Other Pages (new login) · Jobs.
